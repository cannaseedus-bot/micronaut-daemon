📐 Semantic Field Mathematics · 2D Contract

Unigrams, bigrams and trigrams have distinct responsibilities. The field combines symbolic graph topology with numeric 2D geometry; semantic references are not automatically numeric tensors.

U₁
Frozen corpus prior W_C(w)
B₂
Ordered relation vector (x,y)
T₃
Stored phase θ + executable FoldRef
W_effective(w,t) = W_corpus(w) × W_learned(w,t)
B₂(wᵢ,wⱼ) → v_b = (x_b,y_b) ∈ ℝ²
G(q,b) = (v_q · v_b) / (||v_q|| ||v_b||)   [nonzero vectors]
T₃ = (wᵢ,wⱼ,wₖ,θ,FoldRef),  θ ∈ {0,1,2,3,4,5}
N(k) = N_manifest(k) ∪ N_inferred(k)
M_F(h) = Σ_τ B_τ[h,*] ⊗ W_τ

The ⊗ symbol above denotes edge-wise weighting in this proposed field law; it does not require tensor contraction. Manifest and inferred evidence must remain distinguishable. The corpus prior is immutable; learned modifiers are stored separately.

🧲 WCR Routing and Micronaut Field Bias

XCFE gates admission independently of scoring. For an admitted fold, the illustrative routing score is S = W × C × R × Gₘ × Lₘ, where Gₘ is geometric compatibility and Lₘ is the Micronaut's learned route modifier.

Illustrative score: 0.4590

Demo uses nonnegative normalized values. Actual runtime must define normalization, sign handling, zero-vector behavior, eligibility and update policies. A high score never bypasses XCFE authority.

Micronaut = Program + Vector + Field Bias + Evolution
S_WCR(f | q) = W(f) × C(f,q) × R(f,q)
S_m(f | q) = S_WCR(f | q) × G_m(f,q) × L_m(f,q)
f* = argmax { S_m(f | q) : XCFE_admit(f,θ,context) = 1 }

📜 XJSON Specification v2.0

XJSON is a universal AST-JSON language capable of representing HTML, CSS, Logic, state, routing, components, SCX blocks, agents, and OS-level layout — all in one JSON tree.

Core Node Types

{
  "type": "element",   // HTML/UI element
  "type": "style",     // CSS/SCX styles
  "type": "logic",     // JS/PY/PHP logic
  "type": "control",   // @if/@then/@else flow
  "type": "component", // Reusable UI
  "type": "route",     // Navigation
  "type": "state",     // Application state
  "type": "agent",     // MX2LM/Mx2Qwen agent
  "type": "tape"       // Holotape OS
}
💡 Key Insight: XJSON is 100% valid JSON. Every node is declarative and combinable. The ASX Runtime interprets it directly — no compilation step.

⚛️ Atomic ASX Runtime

The ASX Runtime is a framework-free JavaScript engine that interprets XJSON directly. One file ships an app: $state, $routes, $effects.

{
  "$schema": "asx-shell-v1",
  "$state": { "user": { "score": 0 } },
  "$computed": { "userLevel": "Math.floor(get('user.score') / 100)" },
  "$effects": [
    {
      "when": "user.score",
      "run": {
        "op": "if",
        "test": { "gte": [{ "$get": "user.score" }, 100] },
        "then": [{ "op": "notify", "message": "Level up!" }]
      }
    }
  ],
  "$routes": { "home": { "sections": [{ "panel": { "title": "Welcome" } }] } }
}

🔒 Security Model

  • Trust Stamps — Signed tapes prevent tampering
  • Agent Sandboxing — Isolated execution contexts
  • No eval() — Declarative control flow only
  • Cipher Rotation — SCX tokens remappable per session

✅ Best Practices

  • Initialize all state; avoid undefined paths
  • Use computed values for derived data
  • Use SCX glyphs for repeated patterns → 90% compression
  • Never use eval() — only parse whitelisted tokens
